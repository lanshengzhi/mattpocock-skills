Add **`minimal-code`**, a model-invoked engineering skill: the shared discipline for writing the least code that works. It carries the ladder (YAGNI, reuse in codebase, standard library, native platform feature, installed dependency, one line, minimum), the rules that follow from it, a never-cut list (trust-boundary validation, data-loss error handling, security, accessibility, verification), a `debt:` comment convention for marking deferred shortcuts with their ceiling and upgrade trigger, and an output rule (code first, at most three lines of explanation). `tdd` gains a pointer to it for green-phase implementations, and `ask-matt` maps it in the vocabulary layer.
